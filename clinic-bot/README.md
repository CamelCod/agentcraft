# Clinic Bot — WhatsApp Appointment Automation

A zero-LLM, state-machine-driven WhatsApp booking system for UAE private clinics. Patients book appointments, receive reminders, and leave feedback — all via WhatsApp buttons and lists in their native language.

## Architecture

```
WhatsApp Patient ──► Meta Cloud API ──► Make.com
                                            │
                         ┌──────────────────┼──────────────────┐
                         │                  │                   │
                    Scenario 1         Scenario 2          Google Sheets
                   (Inbound)          (Scheduler)          (Data Store)
                  State Machine       Reminders +
                  Booking Flow        No-show Recovery
```

**Two Make.com scenarios, one Google Spreadsheet, zero LLM costs.**

## State Machine

```
NEW
 └─► AWAIT_LANG (bilingual welcome + AR / Other buttons)
       ├─► Arabic selected ──────────────────────► AWAIT_SPECIALTY
       └─► Other selected ──► AWAIT_LANG2 (6-lang list) ──► AWAIT_SPECIALTY
                                                                    │
                                                               AWAIT_DOCTOR
                                                                    │
                                                               AWAIT_DATE
                                                                    │
                                                               AWAIT_TIME
                                                                    │
                                               ┌────────────────────┤
                                               │ new patient        │ returning patient
                                          AWAIT_NAME           AWAIT_CONFIRM
                                               └─────────────► AWAIT_CONFIRM
                                                                    │
                                                    ┌───────────────┤
                                                    │ confirm       │ cancel
                                                  DONE ◄───────────┘
                                                (Scheduled)    (Cleared)

Async states (set by Scenario 2):
  AWAIT_FEEDBACK  ─► patient rates 1-5 ─► if ≥4: send Google Review link
  AWAIT_NOSHOW    ─► reschedule / dismiss
```

## Meta Message Templates

Create these 5 templates in [Meta Business Manager](https://business.facebook.com/wa/manage/message-templates/) before activating Scenario 2. Approval takes 1–3 business days.

### `clinic_reminder_24h`
**Category**: UTILITY  
**Body** (variables in order): `{{1}}` patient name, `{{2}}` doctor name, `{{3}}` date/time
```
Hi {{1}}, this is a reminder that you have an appointment with Dr. {{2}} tomorrow at {{3}}.
Reply CONFIRM to confirm or CANCEL to cancel.
```

### `clinic_reminder_2h`
**Category**: UTILITY  
**Body**: same variables as above
```
Hi {{1}}, your appointment with Dr. {{2}} is in 2 hours at {{3}}. See you soon!
```

### `clinic_noshow_recovery`
**Category**: UTILITY  
**Body**: `{{1}}` patient name, `{{2}}` doctor name  
**Buttons**: Quick reply `reschedule` + `dismiss`
```
Hi {{1}}, we missed you today for your appointment with Dr. {{2}}.
Would you like to reschedule?
```

### `clinic_feedback_request`
**Category**: UTILITY  
**Body**: `{{1}}` patient name, `{{2}}` doctor name  
**Buttons**: Quick replies `rate_1` through `rate_5`
```
Hi {{1}}, thank you for visiting us today with Dr. {{2}}.
How would you rate your experience? (1 = Poor, 5 = Excellent)
```

### `clinic_reactivation`
**Category**: MARKETING  
**Body**: `{{1}}` clinic name
```
Hi! It's been a while since your last visit to {{1}}.
Your health matters to us — book your next appointment today!
```

## Filter Configuration in Make.com UI

The blueprints contain text-based filters but **time-based conditions must be added manually** in the Make.com UI after import.

### Scenario 2 — Filter additions per route

**Route 1 (24h reminder)** — add to the filter on module 4:
- `{{3.F}}` > `{{formatDate(addHours(now; 23); "YYYY-MM-DD HH:mm")}}`
- `{{3.F}}` < `{{formatDate(addHours(now; 25); "YYYY-MM-DD HH:mm")}}`

**Route 2 (2h reminder)** — add to the filter on module 7:
- `{{6.F}}` > `{{formatDate(addMinutes(now; 105); "YYYY-MM-DD HH:mm")}}`
- `{{6.F}}` < `{{formatDate(addMinutes(now; 135); "YYYY-MM-DD HH:mm")}}`

**Route 3 (no-show)** — add to the filter on module 10:
- `{{9.F}}` < `{{formatDate(addMinutes(now; -60); "YYYY-MM-DD HH:mm")}}`

**Route 4 (feedback)** — add to the filter on module 15:
- `{{14.F}}` < `{{formatDate(addHours(now; -4); "YYYY-MM-DD HH:mm")}}`

**Route 5 (reactivation)** — replace the placeholder filter on module 20:
- `{{19.J}}` > `{{formatDate(addDays(now; -31); "YYYY-MM-DD")}}`
- `{{19.J}}` < `{{formatDate(addDays(now; -29); "YYYY-MM-DD")}}`

### Scenario 2 — filterRows search criteria

In the Make.com UI, open each `filterRows` module and add search criteria (Google Sheets "Search Rows" filter conditions) to reduce data fetched:

- Modules 3, 6, 9: filter `status = Scheduled`
- Module 14: filter `status = Completed`

### Scenario 1 — filterRows search criteria

- Module 2 (Sessions): filter `phone = {{1.value.messages[].from}}`
- Module 3 (Translations): filter `lang = {{2.B}}` (language from session)

## Replacing Placeholders

After importing or using the live scenarios:

1. **Spreadsheet ID**: Find it in your Google Sheet URL:
   `https://docs.google.com/spreadsheets/d/YOUR_SPREADSHEET_ID/edit`
   
2. **Phone Number ID**: In Meta Business Manager → WhatsApp → Phone Numbers → your number → copy "Phone Number ID"

3. In Make.com: Open each scenario → click each Google Sheets module → update Spreadsheet ID.
   For WhatsApp modules: update the `fromId` field.
